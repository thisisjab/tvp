# TVP - Tiny Video Party

**TVP** (Tiny Video Party) is a lightweight, self-hostable platform for synchronized video watching. It is designed for small groups to watch video content together in real time.

**Status: Early Development**
This project is in active initial development. Features may be incomplete or subject to change.

## Overview

TVP aims to provide a minimal, resource-efficient solution for synchronized video playback. The platform is intended to be self-hosted, giving users control over their data and viewing environment. Core design goals include simplicity, low dependency overhead, and real-time synchronization.
